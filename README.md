# Student-Lifestyle-Academic-Performance-Analysis

# Student Lifestyle & Academic Performance — EDA

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on student lifestyle and academic performance data.

The analysis explores how different lifestyle factors such as **study hours, sleep hours, social hours, physical activity, extracurricular activities, and stress level** are associated with students' academic performance measured by GPA.

The project focuses entirely on understanding the dataset, identifying patterns, analyzing relationships, detecting outliers, and communicating meaningful insights.

> **Note:** This project is focused on Exploratory Data Analysis. Machine Learning is not used.

---

## 🎯 Objectives

* Understand the structure and characteristics of the dataset.
* Analyze student lifestyle patterns.
* Study the distribution of lifestyle and academic variables.
* Explore relationships between lifestyle factors and GPA.
* Analyze differences in GPA across stress levels.
* Identify potential outliers using statistical methods.
* Create meaningful visualizations.
* Extract key insights from the data.

---

## 📊 Dataset

**Dataset:** Student Lifestyle & Academic Performance Dataset

**Records:** 2,000 students

**Columns:** 8

### Variables

| Variable                          | Description                          |
| --------------------------------- | ------------------------------------ |
| `Student_ID`                      | Unique identifier for each student   |
| `Study_Hours_Per_Day`             | Daily study hours                    |
| `Extracurricular_Hours_Per_Day`   | Daily extracurricular activity hours |
| `Sleep_Hours_Per_Day`             | Daily sleep hours                    |
| `Social_Hours_Per_Day`            | Daily social activity hours          |
| `Physical_Activity_Hours_Per_Day` | Daily physical activity hours        |
| `Stress_Level`                    | Student stress level                 |
| `GPA`                             | Grade Point Average                  |
